### 📌 บทเรียนจาก Sprint 1

1. `shared/assets/images/` และ `icons/` **ว่างเปล่า** — ยังไม่มีรูปสินค้า/สถานที่เลย ทั้งที่เป็นเว็บท่องเที่ยว
2. `vercel.json` ทำ clean URL ได้ **เฉพาะบน Vercel** — รันบนเครื่องต้องใช้ path เต็ม
3. CSS ใช้ path absolute → **เปิดไฟล์ตรง ๆ เว็บพัง** ต้องรันผ่าน web server
4. ต้นแบบเป็น dark theme ล้วน — Sprint 2 เปลี่ยนเป็น light เป็นค่าเริ่มต้น
5. **ออกแบบไว้เยอะกว่าที่ implement** — Sprint 2 จึงไม่ใช่ "ย้ายของเก่า" แต่เป็น "ย้าย + สร้างที่ยังไม่มี"

## 🏃 Sprint 2 — เปลี่ยนเป็น React

**เป้าหมาย:** ย้ายต้นแบบ HTML/CSS ไปอยู่บน React (Next.js) **และสร้างหน้าที่ออกแบบไว้แต่ยังไม่มี**
**ผลลัพธ์:** `starter-react/` (เว็บ public) + `admin-react/` (หลังบ้าน)
**เอกสารเทคนิค:** [`MIGRATION_PLAN.md`](./MIGRATION_PLAN.md)

### 🔑 ข้อตกลงของ Sprint นี้

| ข้อ         | ตกลงว่า                                                                         |
| ----------- | ------------------------------------------------------------------------------- |
| โครงสร้าง   | 2 โปรเจกต์แยกกัน คนละ port — ไม่รวมเป็น monorepo                                |
| ธีมเริ่มต้น | **Light mode** (ยังสลับ dark ได้)                                               |
| ธีมภาพรวม   | **ท่องเที่ยว** — ใช้ variant ที่ tech-stack มีอยู่ ปรับสี+ข้อความ               |
| ล็อกอิน     | เตรียมต่อ **Firebase** จริง (ระหว่างยังไม่มีคีย์ ใช้โหมดทดลอง)                  |
| ฐานข้อมูล   | MongoDB Schema ที่ออกแบบใน Sprint 1 — **ยังไม่ต่อจริงใน Sprint 2** วางโครงรอไว้ |
| ขอบเขต      | เน้นวางโครงให้คนอื่นมาต่อได้ ไม่ต้องครบทุกฟีเจอร์                               |

### 🚫 กฎเหล็ก (ผิดข้อไหน = ตีกลับจาก In Progress)

1. ใช้ **`yarn`** เท่านั้น ห้าม `npm install`
2. **ห้ามลบไฟล์ของ tech-stack** — เอาออกจากเมนูได้ แต่ไฟล์ต้องอยู่
3. **ห้ามก๊อป CSS เดิมมาใช้** — ต้องแปลงเป็น MUI theme
4. เช็ก `src/blocks/` ก่อนสร้าง component ใหม่ (มีของให้ใช้เป็นร้อยชิ้น)
5. จุดที่ยังเป็นข้อมูลปลอม ใส่ `// TODO(JSD13):`
